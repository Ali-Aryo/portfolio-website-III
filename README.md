# Ali Shamsi — Personal Portfolio

My personal portfolio site, live at **[ali-shamsi-dev.netlify.app](https://ali-shamsi-dev.netlify.app/)**.

## About Me

I'm a Computer Engineering student at Simon Fraser University, and have Software Engineer industry experience. My experience includes full-stack web development, AI/ML, and embedded hardware. This site is where I bring that work together: a filterable gallery of my projects, each with its own write-up, tech stack, and links.

## Built With

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Framer Motion
- shadcn-style UI primitives (`@base-ui/react`, `class-variance-authority`, `tailwind-merge`)
